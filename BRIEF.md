# BRIEF: Мастерская стен — Лендинг

## О проекте
Лендинг для бригады по гидроизоляции и декоративной 
штукатурке в Ростове-на-Дону.

## Стек
- Frontend: чистый HTML/CSS/JS (index.html)
- Хостинг: VPS (nginx)
- Форма: отправка заявки на email менеджера

## Структура проекта
project/
├── index.html        ← основной файл, дизайн и вёрстка
├── README.md         ← описание дизайна
├── BRIEF.md          ← этот файл
└── assets/
    └── images/       ← фото для галереи до/после

## Что уже готово

## Что нужно реализовать

### Локальное тестирование
- Поднять локальный сервер (python или npx serve)
- Форма квиза должна работать на localhost
- Простой бэкенд-обработчик для отправки на email

### Форма заявки
- Отправка на email: manager@masterskaya-sten.ru
- Письмо содержит: тип услуги, площадь, 
  когда планирует, номер телефона
- Заменить email перед релизом

### SEO
- Мета-теги: title, description, og-теги
- Schema.org JSON-LD (LocalBusiness)
- Ключевые слова по Ростову-на-Дону органично в тексте
- robots.txt
- sitemap.xml
- nginx.conf шаблон для VPS

### Яндекс.Метрика
- Добавить заглушку счётчика с комментарием
- Цели: отправка формы, клик по телефону, 
  использование калькулятора

## Перед релизом (пока пропустить)

- Заменить название "Мастерская стен" на финальное
